システムのメニューとなります。

授業料金管理メニュー
口座引落による授業料などの代
金の請求データ入力や引落結果
の確認、振込による代金の請求
データ入力、返金データ入力を
行うメニュー。

入金管理メニュー

状況の閲覧・出力を行うメ
ニュー。

締管理メニュー

ニュー。

やる気度診断メニュー

込先 ) の入力・修正・閲覧を行う。

Web-SKS メニュー

## Web-SKS メニュー　|　生徒管理メニュー
　　のマークをクリックすると　　のマークになり、生徒管理メニュー配下のメニューが下に表示されます。

①生徒登録
生徒 ( 内部生 ) 情報の入力・変更・閲覧を行う。ここで入力
した生徒は内部生として登録される。新規の生徒は①問合せ
管理のデータ ( 入会日が入力されていることが必要 )、②ＳＫ
Ｓの外部生データ、③ＳＫＳに登録されている併設教室 ( 部門 )
の内部生データ ( スクエア生取込 ) のいずれかから取り込み
を行う。生徒情報には面談情報と受講履歴情報 ( 授業登録 )
を含む。

⑤個別カリキュラム
生徒ごとの授業の進捗に合わせたカリキュラム作成を行
う。結果帳票により、どこが出来て、どこが出来ていな
いかを把握できる。

②外部生登録
外部生 ( 講習生・体験生 ) 情報の入力・変更・閲覧を行う。
新規の外部生の入力は問合せ管理のデータから取り込みを行
う。ETS を実施する講師は、外部生（体験生）として登録する。

⑥生徒集計一覧
学年別の生徒数，入塾・退塾数を一覧画面にて管理できる。
エクセルファイルへの出力も可能。

③生徒名簿一覧
内部生・外部生の生徒情報を一覧形式で表示する。ここから
個々の生徒の情報を入力・変更・閲覧したり、葉書やタック
紙へ住所を印字、もしくはエクセルに任意の生徒情報を出力
することができる。

⑦成績管理メニュー
生徒の成績情報をテスト毎（定期テスト、C テスト、通知
表等）や中学校別（2 学期 /3 学期制）に入力・更新を行い、
成績カルテやレーダーチャート等の出力を行う事ができ
る。

④受講履歴登録
授業開始・受講コース・退塾・入塾（再入塾）などの情報の
入力・変更・閲覧を行う。ここで登録されたコースは、ワイ
ドネット授業料の請求に自動的に反映する。

⑧PCS 実施状況一覧
PCS の実施率や実施状況を一覧で参照できる。
エクセルファイルへの出力も可能。

## Web-SKS メニュー　|　受講料金管理メニュー　｜　ワイドネット者メニュー
　　のマークをクリックすると　　のマークになり、生徒管理メニュー配下のメニューが下に表示されます。
受講料金管理メニュー、振込者メニュー、調整メニュー、受講料金関係帳票メニューから更にメニューが広がります。
、

生徒の授業料等の支払い方法が
ワイドネット（口座引落）者の管理メニューです。

①-1 ワイドネット引落不能 CVS 振替
ワイドネット（口座引き落とし）が不能であった場合に、再
引落指定するのではなく、コンビニ決済の請求書を発行し、
請求をかける。

①-2 ワイドネット引落結果確認
引落結果の閲覧・印刷を行う。

①-3  ワイドネット再引落指定
引落不能者の次回ワイドネットへの再引落を指定する。再引
落の指定は、引落結果が反映されてからワイドネット請求締
めを行うまでの間のみ実行できる。次回ワイドネット引落の
際に再引落の金額が加算される。

①-5  ワイドネット者用料金入力
ワイドネット者用請求データ作成で作成されるデータ
( 毎月の授業料と年２回の維持管理費 ) 以外の費用を入
力する。ワイドネット者用請求データ作成実行後に利
用できる。

①-6  ワイドネット請求締処理
口座引落データの入力が完了した際に実行する。入力締
切日までに実行する必要がある。これを実行しないと口
座引落は行われない。また、実行後は口座引落データを
一切修正できないので、ワイドネット請求締め実行前に
慎重に確認する必要がある。なお、複数の部門 (IE、
WinBe、Child) を開設している場合でも、１部門で実行
すれば全部門のワイドネット請求締め処理が行われる。

①-4  ワイドネット者用請求データ作成
口座引落を行うデータを作成する。前月の月次処理後から当
月のワイドネット者用料金入力実行 ( ワイドネット者用入金入
力の実行が必要ない場合は、ワイドネット請求締め ) までの間
に毎月実行する必要がある。作成されるデータは、ワイドネッ
ト者に登録されている生徒の毎月の授業料、および年２回の
維持管理費。これら以外の費用 ( たとえば増コマ、教材費、講
習費など ) は、別途ワイドネット者用料金入力でデータを作成
する必要がある。なお、ワイドネット者用データ作成実行後に、
①新規登録した生徒の請求データを追加作成したり、②授業
コースを変更もしくは退塾による請求変更がある場合は、該
当する生徒の請求データを削除し生徒登録を変更した上で、
再度ワイドネット者用データ作成を実行する必要がある。
締処理にて請求データが作成される前提条件は、以下の通り。
①生徒登録の「引落開始年月」が設定されている事。
②生徒登録の「口座情報」が登録されている事。
③受講履歴登録の「受講コース」が設定されている事。

振込者メニューではコンビニ決済の

②-1 振込者用料金入力
コンビニ振込による請求データを作成する。振込者だけでな
く、ワイドネット者や外部生に対する振込請求データもここ

②-2 コンビニ振込用紙発行依頼
コンビニでの払い込みができる請求書（振込用紙）を発行依

## 調整入力メニュー
③-1 調整入力
①ワイドネット者用料金入力・振込者用料金入力で入
力できない金額 ( たとえばコース変更による差額など )
や、②返金のデータを入力する。生徒１名につき返金か
追加徴収のいずれかを月 1 回のみ入力できる。返金に
ついては、振込で返金するか次回ワイドネットで相殺
するかを選択できる。次回ワイドネット相殺は、次回
ワイドネットの請求金額が返金金額を上回る場合のみ
可能。なお、返金の入力をしないとロイヤルティの返
金ができない。また、振込での返金作業は教室で行う ( 本
部から返金手続きを行うことはない )。

③-2 返金一覧
調整入力で入力した振込による返金データや調整した金
額を閲覧する。
エクセルにデータを出力することもできる。

教室での月次処理を行うメニュー。

①-1 20 日締処理
ロイヤルティの算出に基づく、請求や返金データを締めま
す。当処理で締めたデータを締めます。
当処理で締めたデータで、後日、ロイヤルティを発行しま
す。

①-2 教室用月次処理
１ヶ月間の請求や入金を確定する。これを行わないと、翌
月の処理が開始できない。月末に実行する。また、実行後
は請求・入金などのデータは一切変更できなくなるので、
教室用月次処理実行前に慎重に確認する必要がある。なお、
複数の部門（IE、WinBe、Child）を開設している場合でも、
１部門で実行すれば全部門の月次処理が行われる。

問い合わせ管理

Web-SKS の機能のひとつ、問い合わせ管理についての説明です。

教室に問い合わせがあった場合には、下の手順に沿って、問い合わせ状況を入力し、問い合わせから入塾面談、入塾に至

るまでを管理します。

Web-SKS にログインし、

「生徒管理メニュー」の「生徒登録」をクリックし、

「生徒登録」の画面を開きます。

「生徒登録」の画面の左上にある、

「問い合わせ管理起動」のボタンをクリックすると、

「問い合わせ管理」の画面が開きます。

「登録」ボタンをクリックし、

登録画面を表示します。

アクセスレベル１・２は、個別カリキュラム、成績管理メニュー、
やる気度診断メニューのみ利用可能。
３はすべての操作が可能です。

区分を設定します。
区分「0:利用中」の場合のみ、ログインが可能となり、「1:削除」にした場合
には、ログインメニューに表示されなくなります。

学校登録

マスタ管理メニュー

マスタ管理メニュー｜学校登録

内部生・外部生の生徒情報のうち、小学校・中学校・高校データの入力・修正・閲覧を行う画面です。

ここに学校が登録されていないと生徒登録・外部生登録で学校を登録できませんので、生徒登録で該当する学校が無い場

合には、この画面で登録を行います。

## 学校登録をする
「マスタ管理メニュー」→「学校登録」のメニューを開きます。

既に登録されている学校の一覧が表示されます。
※登録が 1 件もない場合には、何も表示されません。

学校コードを入力します。
※学校コードは、各教室で分類し易いと思われる、任意のコー
ドを入力します。
※学校区分が１〜４の区分があるため、区分と合わせて、1:
小学校であれば、1001 のようなコードが望ましい。

学校区分　1: 小学校　2: 中学校　3: 高校　4: 大学　の４区分
の中から選択します。

学校名欄を入力します。○○○小学校のように、「小学校」
「中学校」「高校」「大学」まで入力しないでください。

フリガナを入力し、0: 公立　1: 私立　2：国立　3：公立中高
一貫　4：私立中高一貫の学校分類を選択してください。

削除区分　0: 通常　1: 削除　のうち、1: 削除を選択した場合
には、生徒登録時、その学校を登録する事は出来なくなります。

「追加・修正」ボタンを押すと登録完了します。
